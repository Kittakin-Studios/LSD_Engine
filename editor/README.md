# editor

`lsd_editor`: the editor app (Unreal-style workflow). Current state is the editor shell: dockable
Viewport (grid, axis gizmo, orbit camera), Outliner, Details and Content Browser, styled by the
reflected `EditorTheme` (`editor_theme.h`, saved to `Config/editor_theme.json`).

Outliner and Content Browser show sample data until the World (milestone 3) and the asset
registry (milestone 2) exist.
